### [v1.1.0] '26.9.18
:::warning
**クリーンインストール推奨**
:::

- **新機能実装**  
    ConnectionMode時に右手をPoint Gestureにすると「**ビーム選択モード**」に切り替わるようになりました。  
    ビーム選択モード時、ビームを接続したい人に1秒ほど当てることで接続が可能になります。  
    ※距離は基本8m(アバタースケール依存)。射線上のプレイヤー全員に接続されるため注意してください。  
    既存の仕様としてすでに接続しているプレイヤーがいる場合はビームで触れてしまうとChannelが上書きされてしまうのでご注意ください。  

- **その他微修正**  
    - ConnectionMode時の魔方陣の位置調整がある程度自動で行われるようになりました。  
    -[ミダリス](https://booth.pm/ja/items/8775542)ちゃん等、一部のArmature名が特殊なアバターでも導入できるようにしました。  
        ※依然として標準外のArmatureのアバターへの手動調整は必要です。  
        本バージョンでも導入できないアバターがありましたらご連絡ください。

### [v1.2.0] '26.10.20
:::warning
**破壊的変更を伴うため必ずクリーンインストールしてください。**  
更新の際はSenshuBanko配下の下記フォルダを削除してください。  
- DBT_CoreModule
- MomiTools
- SecretTalkSystem
:::

- **内部処理の一部変更**  
    - 内部処理用に新規Componentを追加しました。この更新に伴い以下の修正が入ります。  
      - 一部のHashedits製FTアドオンにて目が動かなかった問題を修正しました。  
      - Humanoid AvatarのMappingでEyeボーンを指定していない場合はそのままの状態が維持されます。(ハオラン君等)  
      - 標準外Armatureでもほぼ追加対応不要で実装できるようになりました。  
    　  (Aポーズの場合はCollisionCheck_Positionの角度調整が必要になります。)
      - EyeボーンにRotaitionConstraintを使用するため、**視線追従系ギミックとの併用が出来なくなりました。**  

- **その他微修正**  
    - ドローンの追従モード時、GestureをPoint→Idleに変更しても追従状態が維持されるように変更。  
        - Indexコントローラーでもドローンのモード変更をしやすくなりました。  
    - 初期状態でドローンの本体が90度回転していた問題を修正。  

- **FaceEmo併用時について**  
    - FaceEmo併用時はアバターのWDをオンに統一してください。  
        - FaceEmoがWDオフ依存のUnityのバグを踏んでおり、WDオフ環境だとSTSの動作が不安定になります。  
        - この問題はSTS以外のDBT/AAPを使用しているギミック全般に影響します。
